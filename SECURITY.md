# Security Policy

## Supported Versions

Easypygamewidgets does not create security updates for older versions. If you want to get the newest security fixes you need to download the latest update.

## Reporting a Vulnerability

Found a vulnerability?

- **Check existing issues:** Make sure the vulnerability hasn't already been reported [here](https://github.com/PizzaPost/easypygamewidgets/issues).
- **Open a new issue:** Open an issue describing it.
- **Example:** Give a minimal example code so that we can reproduce the vulnerability.
